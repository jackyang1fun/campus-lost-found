## 3. RTM 使用方式

1. 在当前 `rtm-v1.1.csv` 中按需求 ID 查找设计模块、实现文件和测试用例。
2. 需求变更后不得删除基线行，应新增需求版本并修改“变更状态”。
3. 每次代码修改至少更新一个实现文件映射；每次行为变化至少更新一个测试映射。
4. 完整验收结果见 `docs/03-implementation/acceptance-test-report.md`。
