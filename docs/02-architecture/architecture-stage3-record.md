## 3. R1：认领完成事务与恢复保护

### 3.1 认领完成事务

`ClaimCompletionCoordinator` 在同一个 SQLite 事务内完成：

1. 验证当前用户是信息发布者且认领处于协商中；
2. 将目标认领更新为已完成；
3. 将关联信息更新为已解决；
4. 将同一信息其他“协商中”认领更新为已取消；
5. 写入状态变更审计记录；
6. 提交事务。

任何步骤失败时全部回滚，并返回可访问的错误提示。该细节防止“认领已完成但物品仍公开”或“物品已解决但其他认领仍可写消息”的半完成状态。

### 3.2 备份恢复保护

`BackupRestoreCoordinator` 在恢复时执行：

1. 获取应用级恢复门禁，暂停新的写操作；
2. 校验备份文件格式、SQLite 完整性和数据库版本；
3. 为当前数据库创建恢复前安全副本；
4. 原子替换当前数据库文件；
5. 重新打开并校验外键与关键表；
6. 成功则更新备份记录并恢复写入，失败则回退到安全副本；
7. 全程记录审计结果。

单实例运行通过 `SingleInstanceGuard` 保障，防止两个应用进程同时写同一个数据库或执行恢复。

## 4. R2：统一无障碍宿主

`AccessibilityHost` 分为四个职责：

| 组件 | 职责 |
|---|---|
| `AccessibleControlRegistry` | 为按钮、输入框、列表、菜单和状态控件设置名称、描述、角色和当前状态 |
| `FocusOrderCoordinator` | 按视觉顺序配置 Tab 顺序；弹窗关闭后将焦点送回触发控件 |
| `ScreenReaderAnnouncer` | 播报错误、成功、异步状态变化和关键业务结果 |
| `SystemThemeAdapter` | 跟随 Windows 高对比度、系统颜色和显示缩放比例 |

所有 WinForms 页面必须通过该宿主配置交互控件，不允许仅依赖默认控件文本或颜色表达状态。

## 5. 本地调整理由

| 调整 | 关联风险 | 关联需求 |
|---|---|---|
| 认领完成采用单事务 | 防止跨表半完成和多个认领同时成功 | FR-CLAIM-005, FR-CLAIM-006, NFR-REL-002 |
| 恢复门禁与回退副本 | 防止损坏备份覆盖当前数据 | FR-BACKUP-004, FR-BACKUP-005, NFR-REL-002 |
| 单实例保护 | 防止并发写入和恢复冲突 | NFR-REL-001, NFR-REL-002 |
| 统一无障碍宿主 | 防止界面迭代造成 Narrator、焦点和高对比度回归 | FR-A11Y-001 至 006, NFR-A11Y-001 至 006 |
