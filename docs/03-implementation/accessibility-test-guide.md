# Lost and Found System 视障听读与无障碍测试指南

## 1. 测试准备

- 使用最终发布目录中的 `LostAndFound.exe`。
- 下列测试账号由本地演示数据初始化脚本创建，仅用于离线演示，不是真实账号。
- 测试账号：`ADMIN-1001 / Admin#2026`、`STU-1001 / Demo#2026` 等。
- 测试过程中只使用键盘、Narrator 和系统高对比度，不使用鼠标。
- 如果需要同时检查两个用户，可在同一个程序内退出并切换账号。

## 2. 启动 Narrator

1. 按 `Windows 徽标键 + Ctrl + Enter` 启动 Narrator。
2. 如果 Narrator 没有立即开始朗读，等待几秒或检查系统音量。
3. 停止当前朗读可以按 `Ctrl`。
4. 退出 Narrator 可以按 `Caps Lock + Esc`。
5. 如果电脑没有 Caps Lock，可在 Narrator 设置中将 Narrator 键改为 Insert。

Narrator 默认将 `Caps Lock` 作为功能键。日常操作仍使用标准 Windows 键盘方式：

- `Tab` / `Shift+Tab`：移动到下一个/上一个控件。
- `Enter` 或 `Space`：执行按钮。
- 方向键：切换列表、表格行或下拉选项。
- `Esc`：关闭窗口内确认浮层。

## 3. 基础朗读检查

逐一使用 Tab 移动焦点，并听清以下内容：

| 检查点 | 应听到或感知到 |
|---|---|
| 校园卡号输入框 | “登录校园卡号，编辑框”及当前内容 |
| 密码输入框 | “登录密码，密码框”，不朗读明文密码 |
| 登录/注册按钮 | 按钮名称及可用状态 |
| 侧边导航 | 工作台、失物广场、发布信息等按钮名称 |
| 搜索框 | 搜索关键词及用途说明 |
| 类别筛选 | 物品分类筛选，并可读出当前选项 |
| 数据表格 | 表格名称、列名和当前行 |
| 状态提示 | 登录失败、认领说明错误等文本 |
| 确认浮层 | 标题、说明、取消和确认按钮 |

任何控件只读出“按钮”“编辑框”而没有用途，都记录为失败。

## 4. 核心流程听读测试

### T01 登录

1. 用 Tab 找到校园卡号输入框。
2. 输入 `STU-1001`。
3. Tab 到密码框，输入 `Demo#2026`。
4. Tab 到登录按钮，按 Enter。
5. 确认 Narrator 读出页面切换和登录成功提示。

### T02 浏览与筛选

1. 使用侧边导航进入“失物广场”。
2. 用 Tab 移动到搜索框，输入“雨伞”后按 Enter。
3. 用 Tab 进入结果表格，用方向键选择一条记录。
4. 确认右侧详情的标题、分类、地点和描述能够被朗读。
5. 确认没有真实图片时会朗读分类类型插画，有图片时会朗读替代文本。

### T03 发起认领与错误提示

1. 选择他人发布的信息，Tab 到“发起认领”并按 Enter。
2. 在认领说明中输入不足 10 个字符并提交。
3. 确认 Narrator 读出错误提示，焦点仍可继续操作。
4. 输入 10 至 200 个字符后提交。
5. 确认匿名会话打开，并读出认领说明、匿名编号和输入框。

### T04 匿名聊天

1. 在聊天输入框中输入“这是一条键盘输入测试消息”。
2. 按 `Ctrl+Enter` 发送。
3. 确认表格或消息列表中出现新消息。
4. 验证读屏不会泄露密码或未公开联系方式。

### T05 管理员审核

1. 退出普通用户，用 `ADMIN-1001` 登录。
2. 进入“审核中心”。
3. 用 Tab 和方向键选择待审核信息。
4. 操作审核按钮时，确认窗口内浮层可以被朗读。
5. 按`Esc`或 Tab 到取消按钮并关闭，确认焦点回到原按钮。

### T06 其他页面

依次进入并听读：

- 发布信息
- 我的发布
- 认领管理
- 消息中心
- 个人中心
- 争议处理
- 用户与日志
- 备份恢复

重点确认表格行列、按钮用途、状态含义和错误信息；不要只检查页面标题。

## 5. 高对比度测试

1. 打开 Windows“设置”。
2. 进入“辅助功能” → “对比度主题”。
3. 选择一种高对比度主题并点击“应用”。
4. 返回应用，重复 T01、T02、T03 和 T05。
5. 检查：
   - 正文和背景是否清楚；
   - 按钮文字和背景是否清楚；
   - 键盘焦点是否仍然可见；
   - 状态不能只依赖颜色；
   - 所有操作仍可完成。
6. 切换回原主题，确认应用不需要重启即可恢复。

也可以使用系统快捷键 `左 Alt + 左 Shift + Print Screen` 切换到默认高对比度主题，但不同 Windows 版本可能关闭该快捷键，因此优先使用系统设置页面。

## 6. 显示缩放测试

在“设置 → 系统 → 显示 → 缩放”分别测试：

- 100%
- 125%
- 150%
- 200%

每次检查登录、发布、失物广场、审核和聊天页面，确认按钮没有被遮挡，正文没有截断，表格仍可横向或纵向滚动。

## 8. 判定标准

只有以下条件同时满足，才能将无障碍专项判定为通过：

1. 核心流程无需鼠标即可完成。
2. 每个交互控件都有能被理解的中文名称。
3. 密码不会以明文被朗读。
4. 表格、列表和下拉选项可以用方向键操作。
5. 弹层打开和关闭后，焦点位置合理。
6. 高对比度下所有核心功能仍可使用。
7. 200% 缩放下核心按钮、字段和错误提示没有被截断。
8. 原有发布、搜索、认领、聊天、审核和管理功能没有中断。
