|---|---|

## 2. 自动化测试结果

执行命令：

```powershell
dotnet test .\LostAndFound.slnx --no-build --no-restore
```

结果：**34 项通过，0 项失败，0 项跳过**。

| 测试域 | 主要覆盖内容 |
|---|---|
| 密码与认证 | PBKDF2 哈希、盐值随机化、登录失败、重复校园卡号、封禁和注销 |
| 用户资料 | 资料更新、密码修改、管理员初始化唯一性 |
| 信息发布 | 发布、编辑、撤销、解决、审核、驳回、公开检索、图片替代文本 |
| 匹配 | 异类信息关联、可解释依据、最多 10 条、忽略候选 |
| 认领 | 不可认领本人信息、重复认领拦截、匿名会话、消息权限 |
| 事务 | 完成认领、解决信息、关闭其他认领在同一事务内完成 |
| 管理员 | 封禁与恢复用户、统计、审计日志、内容删除 |
| 争议 | 参与者提交、非参与者拦截、管理员查看真实身份和聊天 |
| 备份 | 每日自动备份幂等、手动备份、完整性校验、恢复和回退路径 |
| 需求变更 CR-01 | 认领说明必填、10 至 200 字符校验、发布者可见 |

## 4. 无障碍检查

### 已检查

- 登录、发布、搜索、审核、备份及管理按钮具有可读名称。
- WPF 原生按钮、输入框、列表、表格支持键盘聚焦和 Tab 导航。
- 页面切换后将焦点移入当前页面。
- 确认浮层打开后默认聚焦取消按钮，关闭后恢复原焦点。
- 图片具有替代文本，并在展示时设置 UI Automation 名称。
- 高对比度颜色通过动态资源切换到 Windows 系统颜色。
- 状态和错误信息使用文本表达，不仅依赖颜色。

### 仍需人工执行

- 使用 Windows Narrator 完成完整注册、发布、审核、认领和恢复备份流程。
- 在 100%、125%、150%、200% 显示缩放下进行视觉巡检。
- 在 Windows 高对比度主题之间切换，确认所有控件对比度和焦点可见。

这些项目保留为最终课堂演示前的设备验收项。由于当前自动化环境无法可靠驱动系统级屏幕阅读器和高对比度切换，未将自动化测试结果写成“已通过”。

## 5. 发布包验收

- 自包含发布成功。
- 目标电脑无需安装 .NET Runtime。
- 目标电脑无需安装 SQLite 或 MySQL。
- 应用目录包含独立 SQLite 数据库和演示账号说明。
- 整个发布目录可复制到另一台 Windows 10/11 x64 电脑独立运行。
